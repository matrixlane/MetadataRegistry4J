## MODIFIED Requirements

### Requirement: 导航与列表状态展示
系统 MUST 在左侧导航栏提供“语言标识”的编辑/查看入口。语言列表 MUST 清晰展示各语言标识名、文字、地区、以及基于当前系统语言解析得到的语言文字名称（如在中文系统语言下，标识为 `zh-CN` / `en-US` / `ja-JP` 的语言名称分别展示为“中文”、“英文”、“日文”）和国家/地区名称（如在中文系统语言下，标识为 `zh-CN` / `en-US` / `ja-JP` 的国家名称分别展示为“中国”、“美国”、“日本”），以及一个可直接操作的“是否启用”开关，且页面上 MUST NOT 提供任何“新建”或“删除”按钮。

#### Scenario: 访问列表页面
- **WHEN** 用户点击左侧“注册与公共设施”下的“语言标识”
- **THEN** 路由成功跳转到 `/languages`，表格中分页列出所有内置的语言数据，不仅包含原有的语言标识名、文字、地区代码，还包含当前系统语言对应的语言名称与地区/国家名称，并用开关控件显示每个语言的启用状态，没有新建或删除选项
