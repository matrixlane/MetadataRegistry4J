## ADDED Requirements

### Requirement: 限制前台新增用户的系统角色
在后台或前台用户管理中创建或编辑账户时，系统角色选项必须只能选择“普通用户”，禁止新增或变更为“超级管理员”角色。整个系统只允许初始化时创建的单个超级管理员账号拥有该角色。

#### Scenario: 管理员在用户管理中新增用户
- **WHEN** 超级管理员打开用户管理并点击“新建”用户
- **THEN** 系统角色的下拉选项中仅提供“普通用户”选项
- **AND** 无法选择或变更为“超级管理员”

### Requirement: 用户管理列表增加上次登录时间
用户管理列表必须直观展示用户的最近一次登录记录，新增“上次登录时间”列。

#### Scenario: 查看用户列表
- **WHEN** 管理员打开用户管理页面
- **THEN** 表格中包含“上次登录时间”列，并以可读日期格式（如 `YYYY-MM-DD HH:mm:ss`）展示各账号最近登录时间，若从未登录则展示 `-`

### Requirement: 允许自主注册的系统开关与校验
系统必须提供“允许注册新用户”的控制开关（默认开启），在关闭该开关时，访客将无法从前台访问注册接口，且前端登录页面的“注册”按钮应被隐藏。

#### Scenario: 关闭自主注册功能
- **WHEN** 超级管理员在系统设置中关闭“允许注册新用户”开关
- **THEN** 登录页面隐藏“注册”入口按钮
- **AND** 任何调用注册接口 `/api/v1/auth/register` 的请求都会被拒绝，并返回提示“系统已关闭自主注册功能”
