## ADDED Requirements

### Requirement: 数据库语言标识初始化
在系统启动初始化阶段，系统必须检查数据库中的语言标识记录。如果不存在，则必须自动插入 G20 国家所涉及的 22 种常见语言标识（包含 zh-CN、en-US、ja-JP、de-DE、fr-FR、ru-RU、ko-KR 等），且默认状态为“启用”。

#### Scenario: 首次启动初始化语言
- **WHEN** 系统首次运行并执行数据初始化程序
- **THEN** 数据库中成功写入包括 zh-CN、en-US、ja-JP 在内的 G20 常用语言列表，并且 `enabled` 标志全部为 `true`

### Requirement: 导航与列表状态展示
系统必须在左侧导航栏提供“语言标识”的编辑/查看入口。语言列表必须清晰展示各语言标识名、文字、地区以及一个可直接操作的“是否启用”开关，且页面上不提供任何“新建”或“删除”按钮。

#### Scenario: 访问列表页面
- **WHEN** 用户点击左侧“注册与公共设施”下的“语言标识”
- **THEN** 路由成功跳转到 `/languages`，表格中分页列出所有内置的语言数据，并用开关控件显示每个语言的启用状态，没有新建或删除选项

### Requirement: 启用与禁用状态切换
管理员或有权限的用户可以通过点击表格中的启用/禁用开关来立即改变相应语言的启用状态，系统会将状态同步更新回后端数据库。

#### Scenario: 禁用某种语言
- **WHEN** 用户在列表中将“日文 (ja-JP)”的启用状态开关从开启切换为关闭
- **THEN** 系统发起更新请求将该语言的 `enabled` 设置为 `false`，并提示“更新成功”；再次刷新页面时，其状态保持为关闭

### Requirement: 多语言选用过滤
多语言指称（Designation）和定义（Definition）的输入组件在获取语言字典下拉列表时，必须只获取当前处于“启用”状态的语言标识。

#### Scenario: 编辑指称时选择语言
- **WHEN** 用户在数据元编辑器中尝试“添加指称”，并点击“语言”下拉选择框
- **THEN** 列表里只出现目前处于“启用”状态的语言选项，已被禁用的语言选项不予显示
