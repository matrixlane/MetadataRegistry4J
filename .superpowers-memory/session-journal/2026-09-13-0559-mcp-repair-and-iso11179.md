# MCP 修复与 ISO 11179 标准依据核查

日期：2026-09-13

## What Changed

- 回答标准问题：ISO/IEC 11179-3:2023 `Registration_State.effective_date/until_date`（注册管理生命周期日期）与 ISO/IEC 11179-31:2023 `Value_Domain.valid_period`（值域业务有效期）语义正交、不重复、无优先级；依据为 Part 3 §9.4.4 Table 22 与 Part 31 §7.4.2.8.4 Table 5（经 `ISO/IEC 11179 标准原文目录` PDF 原文核实）。
- 修复 Kimi Code 的 milvus MCP：在 `~/.kimi-code/mcp.json` 补注册 milvus server（uv 启动 mcp-server-milvus，参数同 `~/.claude.json`），手动 initialize 握手验证通过（Milvus server v1.25.0）。
- 查明 gitnexus MCP 此前不可用的日志报错（9 月 8–12 日，MODULE_NOT_FOUND）为过期记录；gitnexus 1.6.11 实测握手正常，`MetadataRegistry4j` 在已索引仓库中。
- 在用户级 `~/.agents/AGENTS.md` gitnexus 段新增"MCP 在当前会话不可用时：先诊断修复，再考虑降级"小节。
- 安装 `.superpowers-memory/` 脚手架（install-superpowers-memory.sh），并写入首批记忆条目。

## Decisions

- 值域 `valid_period` 与注册状态日期在模型中都保留；RA 层面可自行约定二者一致，但标准不要求。
- MCP 工具缺失时的默认动作从"直接降级"改为"先诊断修复"（配置注册检查 → 日志辨过期 → 握手实测 → 重启会话）。

## Verification

- milvus MCP initialize 握手返回正常 result（serverInfo: Milvus 1.25.0）；Milvus `:9091/healthz` 返回 200。
- gitnexus MCP initialize 握手正常，repoCount=6 含 MetadataRegistry4j。
- `~/.kimi-code/mcp.json` 修改后经 python json 校验合法。
